# ROS 2 Level2 Course Workspace

This repository contains the ROS2 packages and exercises I created while
completing the "ROS2 for Beginners Level 2 - TF|URDF|RViz|Gazebo" course by Edouard Renard in Udemy.

## Environment

- Ubuntu 24.04
- ROS 2 Jazzy
- URDF, RViz, Gazebo

cd ros2_ws
